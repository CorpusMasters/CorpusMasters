# Dataset Description

## Corpus Information

The corpus consists of Croatian-language doctor reviews collected from the website *Najdoktor*.
All reviews were sentence-tokenized and manually annotated according to five sentiment categories:

* positive
* negative
* neutral
* mixed
* sarcastic

The final corpus contains a total of **2610 sentences**.

---

## Data Splits

The dataset was divided on the review level rather than sentence level.

### Train Set

Total sentences: 2062
* Positive: 1293
* Negative: 550
* Neutral: 153
* Mixed: 54
* Sarcastic: 12

### Validation Set

Total sentences: 272
* Positive: 197
* Negative: 55
* Neutral: 14
* Mixed: 6
* Sarcastic: 0

### Test Set

Total sentences: 276
* Positive: 151
* Negative: 93
* Neutral: 28
* Mixed: 3
* Sarcastic: 1
